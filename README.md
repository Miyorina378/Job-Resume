# Wongsathorn Derochannawong · Portfolio

Personal portfolio and resume of an AI Engineer and Backend Developer in Bangkok.

- **Live site:** https://miyorina378.github.io/portfolio/
- **Resume:** [resume.pdf](resume.pdf)

## What's here

| File | What it is |
| --- | --- |
| `index.html` | The portfolio: a single static page, no build step |
| `img/` | Portrait and project screenshots |
| `resume.html` | Source of the resume, laid out for one A4 page |
| `resume.pdf` | The resume, printed from `resume.html` |

## Update the resume PDF

Edit `resume.html`, open it in Chrome or Edge, press <kbd>Ctrl</kbd>+<kbd>P</kbd>, choose **Save as PDF**, set margins to **None**, and save over `resume.pdf`.

## Publish with GitHub Pages

1. Push this folder to a repository named `portfolio`.
2. In the repository, open **Settings → Pages**.
3. Under **Source**, pick **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.

The site appears at `https://miyorina378.github.io/portfolio/` within a minute or two.
