Featured · AI · Security

CyberSecAI

AI alerts for a network security system

I connected AI to an existing network security system so the security team sees threats as they happen instead of digging through logs. The dashboard sorts detections by severity, source country and hour, and ranks the risks that happen most. An AI insights button summarizes the data, and Spock, a voice assistant, shows new alerts and the top 10 risks to a team that can simply talk to it.

  • 5 severity levels, from low risk to emergency, each with its own count
  • Top risks ranked: suspicious DNS traffic, insecure inbound connections, .exe transfers
  • Bandwidth per protocol over time, with a top-10 table
  • Thai-language interface built for the security team

AI website translation

One corporate website, four languages

I built AI translation for Better Way Group's corporate website, with the backend written in Go. Every page, from the navigation to the brand copy and buttons, is translated by Gemini 2.5 Flash into Thai, English, Japanese and Chinese. Translations are saved in MySQL, so pages load from the database instead of calling the AI on every visit.

  • 4 languages: ไทย, English, 日本語, 中文
  • Whole page translated: menus, headings, body text and buttons
  • Gemini 2.5 Flash does the translating
  • Stored in MySQL and served by a Go backend

Main stack

Go services, built with Hexagonal Architecture

Go is my main language. I structure services as Ports & Adapters: the business logic lives in the core and only talks to the outside through interfaces. HTTP handlers, databases and AI providers are adapters that plug into those ports, so one can be swapped without touching the core, and the core can be unit-tested with mocks.
